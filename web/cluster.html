FROM THIS CONTROLLER

Add a worker

In the Tailscale app, sign both PCs into the same network. On the other PC, open Alice’s Network page and start GPU sharing. Copy its pairing code and public certificate here.

For the worker address, use HTTPS followed by the worker’s IPv4 address copied from Tailscale. If Tailscale was installed after Alice started, restart Alice on that worker to include its new address in the certificate.

A custom CA is optional when the worker already uses a certificate trusted by this machine.
